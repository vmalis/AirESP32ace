# Supporting AirESP32ace

AirESP32ace is free and does not place features behind donations.

## Optional Ko-fi

If the project was useful or simply entertaining, you can optionally support it at [Ko-fi.com/vm216261](https://ko-fi.com/vm216261).

There is no payment code in the app, no feature is placed behind a donation, and the project remains free and open source regardless of support.

Before posting in a subreddit, read its current self-promotion rules. A project post should stand on its technical content; place the optional support link at the end rather than making it the focus.
